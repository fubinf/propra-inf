[SECTION::goal::trial]
Ich kann mit `sudo apt install` ein Programm auf meinem Debian-System installieren.
[ENDSECTION]


[SECTION::background::default]
Ein Linux-System besteht aus _Paketen_.
Ein Paket enthält ein Programm (oder eine Bibliothek) samt allem, was dazugehört.

Pakete installiert ein _Paketmanager_:
Er lädt das Paket herunter und installiert es mit allen notwendigen Abhängigkeiten.
Auf Debian-basierten Systemen heißt der Paketmanager [TERMREF::apt].

Die Dateien eines Pakets landen in Systemverzeichnissen,
damit alle Benutzer eines Systems das Programm verwenden können.
In diese Verzeichnisse darf nur der Administrator-Benutzer `root` schreiben.
Deshalb brauchen Sie zum Installieren Administratorrechte, die Sie mit dem Werkzeug `sudo` bekommen.
[ENDSECTION]


[SECTION::instructions::detailed]

[NOTICE]
Auf einem Poolrechner der Uni haben Sie keine Administratorrechte.
Auf dem Mac gibt es kein `apt`.
Dort übernimmt `brew` diese Rolle, und zwar ohne `sudo` (siehe [PARTREF::CLI-MacOS-brew]).
In beiden Fällen überspringen Sie diese Aufgabe.

Wer schon weiß, was `sudo` tut, und Pakete mit `apt` installieren kann,
überspringt diese Aufgabe ebenfalls.
[ENDNOTICE]


### Was `sudo` tut

Für diese Aufgabe genügt Folgendes über [TERMREF::sudo]:

- `sudo` steht vor einem Kommando, beispielsweise `sudo apt install jq`.
  Dann läuft nur dieses eine Kommando mit Administratorrechten.
- `sudo` fragt nach Ihrem eigenen Passwort, nicht nach dem von `root`.
- Während Sie das Passwort tippen, erscheint **nichts** auf dem Bildschirm.

[WARNING]
Mit Administratorrechten kann man das System versehentlich beschädigen.
Setzen Sie `sudo` deshalb nur vor Kommandos, bei denen Sie wissen, was sie tun
(im ProPra: wenn eine Aufgabe es ausdrücklich verlangt).
[ENDWARNING]


### Ohne `sudo`

Als Beispiel nehmen wir das Programm `jq`, das noch nicht installiert ist.
Es verarbeitet Daten im JSON-Format.

[EC] Versuchen Sie, `jq` zu installieren:  
`apt install jq`

Lesen Sie die Fehlermeldung.
Sie endet mit der Frage `are you root?` (bei deutscher Spracheinstellung: `sind Sie root?`).

[EC] Die Fehlermeldung nennt eine Datei, die `apt` nicht öffnen konnte.
Sehen Sie sich diese Datei mit `ls -l DATEINAME` genauer an.

Die Ausgabe sieht ungefähr so aus:

```
-rw-r----- 1 root root 0 Jul  9 14:41 /var/lib/dpkg/lock-frontend
```

So lesen Sie sie:

- Das erste `root` ist der Eigentümer der Datei, das zweite die Gruppe, der sie gehört.
- `-rw-r-----` am Anfang sind die Zugriffsrechte.
  Das erste Zeichen (`-`) sagt nur, dass es eine gewöhnliche Datei ist.
  Danach folgen drei Dreiergruppen:
  `rw-` für den Eigentümer (lesen und schreiben),
  `r--` für die Gruppe (nur lesen),
  `---` für alle anderen (gar nichts).

Sie sind weder `root` noch in der Gruppe `root`, gehören also zu "alle anderen"
und dürfen die Datei nicht einmal lesen, geschweige denn schreiben.
Ohne `sudo` läuft `apt` mit Ihren Rechten und scheitert genau daran (`Permission denied` bzw. `Keine Berechtigung`).
Ebenso wenig dürfte es die Programmdateien in Systemverzeichnisse wie `/usr/bin` schreiben.
Mit `sudo` läuft `apt` dagegen mit den Rechten von `root` und darf all das.


### Paketkatalog aktualisieren

`apt` arbeitet mit einem Katalog aller verfügbaren Pakete, der auf Ihrem System gespeichert ist.
`apt update` lädt die neueste Fassung dieses Katalogs herunter, installiert aber noch nichts.
Ist der Katalog veraltet, kennt `apt` neuere Pakete nicht oder versucht, längst ersetzte
Paketversionen herunterzuladen, und scheitert daran.
Deshalb ruft man `apt update` vor `apt install` auf.

[EC] Aktualisieren Sie den Paketkatalog:  
`sudo apt update`

Geben Sie Ihr Passwort ein, wenn Sie danach gefragt werden.

[HINT::`sudo` fehlt oder meldet, ich sei nicht in der sudoers-Datei]
Das passiert, wenn bei der Installation von Debian ein Passwort für `root` vergeben wurde:
Dann richtet der Installer `sudo` für Ihren Benutzer nicht ein.
Holen Sie das als `root` nach:

- `su -` macht Sie zu `root` und fragt dafür nach dem Passwort von `root`.
- Nur falls es `sudo` gar nicht gibt (`command not found`): `apt install sudo`.
- `adduser IHRNAME sudo` nimmt Sie in die Gruppe `sudo` auf.
- `exit` beendet die Shell von `root`.

Melden Sie sich danach ab und wieder an, damit die neue Gruppenzugehörigkeit gilt.
[ENDHINT]


### Paket installieren

`jq` braucht weitere Pakete (Bibliotheken), die `apt` gleich mitinstalliert.
Deshalb fragt `apt` mit `[Y/n]` (bzw. `[J/n]`) nach.
Lesen Sie die angezeigte Paketliste, bevor Sie bestätigen:
Sollen dabei Pakete entfernt werden, brechen Sie im Zweifel mit `n` ab.

[EC] Installieren Sie jetzt `jq`, diesmal mit `sudo`:  
`sudo apt install jq`

[EC] Prüfen Sie, ob das neue Programm funktioniert.
Fast jedes Programm gibt mit der Option `--version` seine Versionsnummer aus:  
`jq --version`
